# 🌮 The Little Taco Shop

A simple multi-page website built while learning the basics of HTML and CSS.

---

## 🌟 What I Learned

* Creating and linking multiple HTML pages (`Home`, `Hours`, `Contact`)
* Using semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<footer>`)
* Building structured tables for menus and prices
* Creating a contact form with input fields
* Organizing images and basic styles in a project folder

---

## 🛠️ Built With

* **HTML5**
* **CSS3**

---

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
